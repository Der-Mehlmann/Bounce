# Bounce

Bounce ist ein abgeschlossenes Lern- und Demonstrationsprojekt: ein Breakout‑ähnliches Mini‑Game, entwickelt als Einstieg in JavaScript und grundlegende Spieleentwicklung im Browser. Es entstand im Rahmen des Moduls „Grundlagen von Browsergames mit JavaScript“ an der Martin‑Luther‑Universität Halle‑Wittenberg.

## Überblick

Ziel des Projekts ist, zentrale Prinzipien der 2D‑Spieleentwicklung praxisnah und kompakt zu vermitteln. Bounce dient als lernorientierte Referenz, wie man mit „vanilla“ JavaScript ein kleines Spiel strukturiert und umsetzt.

## Spielprinzip in Kürze

- Klassisches Breakout‑Konzept: Ein Ball prallt an einem steuerbaren Paddle ab und zerstört Blöcke.
- Kernobjekte: Ball, Paddle, Blöcke, einfache Metriken wie Punkte und Leben.
- Steuerung: Tastatur und/oder Maus (im Spiel erklärt).

## Technische Schwerpunkte

- Spielschleife mit `requestAnimationFrame` (Update → Render)
- Kollisionserkennung (z. B. für Ball‑Block/Paddle)
- Eingabeverarbeitung (Tastatur/Maus)
- Zeichnung und Aktualisierung auf einem HTML5‑Canvas

## Lernziele

- Verständnis für den Aufbau eines minimalen Game Loops
- Umsetzung grundlegender Physik/Kollisionen
- Einstieg in interaktive Anwendungen mit JavaScript

Abgeschlossen.
